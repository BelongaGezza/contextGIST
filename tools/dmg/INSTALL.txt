contextGIST - install instructions (macOS 13 or later)
=======================================================

contextGIST adds "Speed Read with contextGIST" to the macOS Services menu.
Select text in any app that supports Services, choose the item, and a small
popup shows the text one word at a time. Close it and the text is discarded.

INSTALL
  1. Drag contextGIST.app onto the Applications shortcut in this window.
  2. Eject this disk image.
  3. This build is NOT signed or notarized yet, so Gatekeeper will block the
     first launch. To allow it:
       - double-click contextGIST in /Applications (macOS will refuse), then
         go to System Settings -> Privacy & Security, scroll down and click
         "Open Anyway", and confirm.
     Only do this for a copy you got from a source you trust. If a SHA256SUMS
     file came with the download, check it first:
           shasum -a 256 contextGIST.dmg
  4. Launch it once (double-click it in /Applications). Nothing visible
     happens - it has no Dock icon or window - and it quits itself after
     about 10 seconds. That registers the Services item.

USE
  Select text -> right-click -> Services -> Speed Read with contextGIST.
  To assign a keyboard shortcut: System Settings -> Keyboard -> Keyboard
  Shortcuts... -> Services -> Text.

IF THE MENU ITEM DOES NOT APPEAR
  Most apps pick it up after step 4. If yours doesn't, in Terminal:
       /System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister -f /Applications/contextGIST.app
       /System/Library/CoreServices/pbs -flush
  If it still isn't there, log out and back in. As a last resort for a
  Gatekeeper block that "Open Anyway" does not clear (it removes a safety
  check, so only for a copy you trust):
       xattr -dr com.apple.quarantine /Applications/contextGIST.app

REMOVE
  Quit it if running, then drag /Applications/contextGIST.app to the Trash.
  That is all that is needed: contextGIST stores nothing on your Mac. The
  Services item disappears by itself (log out and back in if it lingers).
  Optional, for zero trace - macOS creates an empty sandbox folder for the
  app. In Terminal:
       rm -rf "$HOME/Library/Containers/com.contextgist.macos"
  If the app crashed, a crash report in ~/Library/Logs/DiagnosticReports may
  contain the text you had selected; delete it before sharing anything.
