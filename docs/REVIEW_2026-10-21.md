# Security and quality review — 2026-10-21

Two independent read-only reviews (a security specialist and a quality
specialist, both senior-model agents) covered the whole repository: Rust core,
macOS app, Windows capture spike, tooling, CI, committed binaries and docs.
This file is the consolidated record. It is **findings and decisions only**:
no code, CI or repo-setting was changed as a result; those fixes are listed in
"Pending fixes" for the owner to schedule. Docs were updated to stop
over-claiming (see "Doc changes made").

**Trust level.** Findings below are the reviewers' reports. The author
re-checked only: the Swift `Double` vs Rust `f32` mismatch in
`tokenDurationMs` (source read; the 66-of-901 mismatch count is the
reviewer's brute-force result), the BSD `sed -i ''` in `upstream-review.sh`,
and the merged state of PRs #1–#3. Everything else is marked as reported. The
reviewers could not build or run Swift on Windows; Swift items marked
*(reasoned)* come from reading code.

Baseline verified by the reviewers (at the time): `cargo test --workspace
--locked` 15/15, `cargo clippy -D warnings` clean, `cargo doc` clean, `cargo deny`
passes, `bash -n` passes on all 7 scripts, `cargo fmt --all --check` failing.
**Status at 2026-10-21 end of day:** 25/25 tests, fmt and clippy clean and
CI-gated; see "Pending fixes" for what remains.

## Verdicts

- **Security:** small attack surface; macOS source clean (no network, file,
  logging or pasteboard-write code; Debug test hooks absent from Release). Do
  **not** ship the committed DMG (S-01). Windows: nothing shippable; the spike
  must not be reused as production code (S-02–S-04, S-14).
- **Quality:** Rust core good. Cross-language parity is weaker than the docs
  claim (Q-01, Q-02). CI does not build or lint the Windows spike (Q-03).
  Windows is pre-W0.5: the spike is a sketch, not a benchmark, and no go/no-go
  can be drawn from it yet.

## Windows test strategy additions

Pyramid: unit (core, spike helpers) → golden parity on every OS (same bytes)
→ UIA capture matrix (≥ 60 trials per core app incl. new and classic Notepad,
Edge, Chrome, Word, VS Code; warm and cold; Wilson 95 % lower bound ≥ 90 %;
p50/p95/max with *n*; first-attempt latency reported separately from the retry
sleep; plus Firefox, Edge PDF, Acrobat, Slack/Teams, conhost, an elevated app,
password fields, multi-line CRLF/CJK/RTL/emoji, an over-cap selection, and a
suspended-process hang test) → UI/soak (10-minute 1000 WPM frame deltas logging
indices only; no-focus-steal; `WDA_EXCLUDEFROMCAPTURE`; Narrator script;
drop-counter) → installer (clean VM install/upgrade/uninstall, leftovers,
signature). Missing from earlier exit criteria: sample sizes and a statistical
rule, new Notepad, RichEdit offsets, crash-dump/no-text-in-logs check,
DPI/multi-monitor, uninstall/no-persistence check, hotkey-conflict handling,
cold-start budget.
